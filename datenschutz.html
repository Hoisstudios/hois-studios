Diese Website dient der Information über Hois Studios. Es gibt kein Kontaktformular, keinen Newsletter, keinen Shop, keine Analyse-Tools und kein eigenes Tracking.

Hosting über GitHub Pages

Die Website wird als statische Website über GitHub Pages bereitgestellt. Beim Aufruf der Seiten können technisch notwendige Zugriffsdaten verarbeitet werden. Dazu können insbesondere IP-Adresse, Datum und Uhrzeit des Zugriffs, Browser- und Geräteinformationen, angeforderte Dateien sowie Referrer-Informationen gehören.

Die Verarbeitung erfolgt, damit die Website technisch ausgeliefert, stabil betrieben und vor Missbrauch geschützt werden kann.
